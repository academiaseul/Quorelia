How it works

One path from the sensor to the signed figure

The architecture is deliberately simple. Data enters once, is validated once, and no result reaches a report without passing the verification engine first.

Input SCADA · plant data Inverters, meters, weather stations, BMS. The asset owner's own systems — nothing is replaced.
/01 Quorelia ingestion One 300-second cadence, one timestamp convention, one unit system — regardless of the source.
/02 Data validation Gaps, frozen channels, out-of-range values and clock drift are flagged before anything is computed.
/03a KPI calculation Availability, capacity factor, round-trip efficiency, curtailment — each with its formula recorded.
/03b Data quality engine Coverage, sample count and cycle closure, measured against the thresholds in force.
/04 Verification engine The gate. A figure that fails coverage or cycle closure is not published — the reason is published instead.

Boardroom

One version of operational reality

Readable by an engineer and by a board in the same document. Each technology defines «operation» differently — a turbine idle for lack of wind is not unavailable — but what makes a figure valid can be identical across all of them.

The rule that governs every figure

If the data cannot support a defensible number, we do not estimate it. We flag it.

A withheld figure with its reason stated is verifiable. An estimated figure that looks confident is not. A channel that returns nothing is reported as not observed and excluded from the denominator — never as zero.
